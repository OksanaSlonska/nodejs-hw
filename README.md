Node.js Homework — Note API (MongoDB + Mongoose)

Сервер на Express, створений для роботи з колекцією нотаток.
Реалізовано маршрути для створення, отримання, оновлення та видалення нотаток, підключено базу даних MongoDB, додано логування, обробку помилок і структурування проєкту.

🧩 Функціонал

Підключення до бази даних MongoDB через Mongoose

CRUD-операції для колекції нотаток (GET, POST, PATCH, DELETE)

Логування HTTP-запитів за допомогою pino-http

Обробка 404 та глобальних помилок

Структура коду з поділом на контролери, маршрути, middleware та моделі
